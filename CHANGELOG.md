## [0.1.0] - 2026-08-20

First public release. Everything below is new.

### Added

- Background handling: bokeh blur, image replacement, solid colour, virtual
  green screen and a transparent mode that exports alpha with snapshots.
- Colour grading — exposure, contrast, saturation, temperature, tint, gamma —
  plus 3D `.cube` LUT support and six LUTs generated by `scripts/make_assets.py`.
- Retouching: edge-preserving skin smoothing, sharpening and vignette.
- Auto-framing that follows the AI matte, or a detected face when matting is off.
- Virtual camera output through v4l2loopback, recording through ffmpeg with
  VAAPI hardware encoding on the AMD card, and stills.
- Camera hardware controls (exposure, gain, white balance and so on) read
  straight from V4L2, with a way back to the camera's defaults.
- Configurable output resolution, so you can capture at 1080p and output 720p
  and let auto-framing crop real pixels instead of upscaling.
- Presets that save and restore the whole look.

### Fixed

- Auto-framing stretched the image by 1.78x: the crop was computed by
  multiplying the aspect ratio into two quantities that were each normalised
  against a different axis, giving the crop an aspect of `aspect²`.
- Background image replacement did nothing at all —
  `BackgroundCompositor.set_image()` was never called anywhere, so the
  compositor silently fell back to a solid colour.
- Capture ran at half the frame rate (30 to 16 fps at 720p) because
  `CAP_PROP_BUFFERSIZE` was set to 1.
- Retouching used the pre-crop alpha, so its mask was misaligned once
  auto-framing was on.
- Resolution and encoder dropdowns always selected the first entry:
  `QComboBox.findData` compares non-trivial Python values by identity.
- Every label and slider rendered with a dark box behind it and square handles,
  because the Qt stylesheet set `background` on the blanket `QWidget` rule.
- Toggles had no knob and combo boxes had no arrow — neither can be drawn with
  a Qt stylesheet alone.
- `scripts/setup_v4l2loopback.sh` reported success while creating nothing:
  `modprobe` ignores parameters for an already-loaded module, and the config
  file it wrote was overridden by another one later in alphabetical order.
- Scrolling the control panel could change a slider or combo box under the
  cursor.
- Recordings taken in the same second overwrote each other.
